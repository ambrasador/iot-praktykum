# iot-praktykum

Комплект перевірки практикуму «Технології розробки додатків для інтернету речей» (ХНТУ, спеціальність F2 «Інженерія програмного забезпечення»). Автор: Комісаров О. С.

Вісім практичних робіт розвивають один застосунок — [greenhouse-monitor](https://github.com/ambrasador/greenhouse-monitor). Тут лежить те, чим виконання перевіряють.

| Шлях | Файлів | Що в ньому |
|---|---|---|
| `kit/` | 66 | журнал `track.json` і його команди, контроль кожної роботи, паспорти п'яти варіантів, формули підручника |
| `listingy/` | 28 | код лістингів із тексту практикуму; куди його класти, сказано в `README_PRN.txt` |
| `README_PR1.txt` … `README_PR8.txt` | 8 | що вводить кожна робота: файли, лістинги, розділи підручника |

## Підготовка каталогу

Потрібні Git, Node.js 22 або новіший і npm.

```
git clone https://github.com/ambrasador/iot-praktykum.git
cd iot-praktykum
git clone https://github.com/ambrasador/greenhouse-monitor.git
cd greenhouse-monitor && npm ci && cd ..
```

Каталог `iot-praktykum` — корінь практикуму: усі команди запускають із нього. Застосунок лежить поруч із `kit/` у каталозі `greenhouse-monitor/`, Git його тут не відстежує. Перші кроки описано в тексті практикуму, ПР1, підрозділ 1.3.

Свої роботи ведіть у власній копії, а не в цьому репозиторії.
