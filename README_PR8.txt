5. ЯК ЗАПУСТИТИ
====================================================================================================
Журнал track.json і каталоги pr01…pr08 уже створено в ПР1. Вхідний контроль ПР8 починається з
перевірки журналу ПР7: помилка в попередній роботі показується тут.

Потрібні Docker Engine 25.0 або новіший із Compose v2 і запущений демон; образ
prom/prometheus:v3.16.0 (близько 390 МБ) завантажте заздалегідь: docker pull
prom/prometheus:v3.16.0. Вільними мають бути порти 8080 і 1883.

Команди інструментів, як їх наведено в тексті роботи (підрозділ 8.4; повні параметри — там):
  node kit/tools/ops-inputs.mjs
  node kit/tools/promtool.mjs check
  node kit/tools/promtool.mjs test
  node kit/tools/promtool.mjs mutants

Контроль:
  node kit/tools/verify.mjs pr08                    рівень, заявлений при init
  node kit/tools/verify.mjs pr08 --level 4          показати, скільки лишилося до рівня «4» (або 5)
  node kit/tools/verify.mjs pr08 --declared-only    пропустити довідкові блоки рівнів вище заявленого
Числа в журнал вносять командою node kit/tools/track.mjs set <ключ> <значення>; node kit/tools/track.mjs show друкує журнал.
